# STL corpus fixtures

Add externally sourced, valid STL files here with an adjacent manifest based on
[`../../CORPUS-FIXTURE-TEMPLATE.md`](../../CORPUS-FIXTURE-TEMPLATE.md).

The existing `stl/valid/rotor.stl` and `stl/valid/releaser.stl` predate this
policy and have no recorded source or licence. Do not use them as examples for
new corpus additions.
